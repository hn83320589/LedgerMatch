## 3. 餘額調節表 2026-03

公式（雙邊格式，理由見 README「設計取捨」）：

```
調整後銀行餘額 = 銀行期末餘額 + 在途存款 + 其他帳面已記銀行未記 − 未兌現項目
調整後帳面餘額 = 帳面期末餘額 + 銀行已收帳面未記 − 銀行已付帳面未記
```

### 甲銀行

銀行期末餘額 = 50,000 + 3,000 + 12,500 − 25,000 + 5,880 + 800 + 800 + 9,970 − 1,234.50 + 7,760 + 12.34 − 450 + 1,500 = **65,537.84**

收款單合計 = 3,000 + 12,500 + 2,000 + 3,880 + 800 + 800 + 10,000 + 4,000 + 4,000 + 1,800 + 650 = 43,430.00；支出合計 = −26,684.50

| 項目 | 建議尚未確認 | 全部建議確認後 |
|---|---|---|
| 帳面期末餘額 | 50,000 + 43,430 − 26,684.50 = **66,745.50** | 再扣手續費 30 + 240 = **66,475.50** |
| 在途存款 | R-0303、R-0304、R-0307、R-0308、R-0309、R-0310、R-0311 = **26,330.00**（7 筆） | R-0310、R-0311 = **2,450.00**（2 筆） |
| 銀行已收帳面未記 | 5,880 + 9,970 + 7,760 + 12.34 + 1,500 = **25,122.34**（5 筆） | 12.34 + 1,500 = **1,512.34**（2 筆） |
| 調整後銀行餘額 | 65,537.84 + 26,330 = **91,867.84** | 65,537.84 + 2,450 = **67,987.84** |
| 調整後帳面餘額 | 66,745.50 + 25,122.34 = **91,867.84** | 66,475.50 + 1,512.34 = **67,987.84** |
| 差異 | 0 | 0 |

若輸入對帳單期末餘額 65,537.84，差異仍為 0。

### 乙銀行

銀行期末餘額 = 20,000 + 1,200 + 500 × 3 − 999 − 18,000 + 2,600 = **6,301.00**

## 4. 計算範例（單元測試資料）

`ReconciliationCalculatorTests.HandExample` 使用另一組資料，涵蓋帳面分錄（支票）與直接列入帳面的入帳：

- 期初 10,000；三月銀行交易 +1,200、+1,960、+4,985、+0.75、−20,000、−3,000（支票兌現）、+800（直接列入帳面）；四月 +555 不計入。
- 收款單 1,200、1,000、960、5,000、2,500，以及 4/1 的 999（不計入三月）。
- 配對：1,200 精確已確認；1,960 = 1,000 + 960 建議；4,985 + 手續費 15 = 5,000 已確認。
- 帳面分錄：支票 −3,000（已由 −3,000 兌現）、支票 −1,500（未兌現）、其他調整 +100。

| 項目 | 金額 |
|---|---|
| 銀行期末餘額 | −4,054.25 |
| 帳面期末餘額 | 10,000 + 10,660 − 4,400 − 15 − 19,200 = −2,955.00 |
| 在途存款 | 1,000 + 960 + 2,500 = 4,460.00 |
| 其他帳面已記銀行未記 | 100.00 |
| 未兌現項目 | −1,500.00 |
| 銀行已收帳面未記 | 1,960 + 0.75 = 1,960.75 |
| 調整後銀行餘額 = 調整後帳面餘額 | −994.25 |
